# 网盘直链下载助手 · 自用精简版（panlink-lite）

![License](https://img.shields.io/badge/license-AGPL--3.0-blue)

油猴脚本：在网页里勾选文件，一键拿到网盘**官方接口的直链下载地址**，通过 aria2c 命令或 RPC 推送给 Motrix / Rayburst / aria2 下载。

支持 **百度网盘 / 阿里云盘（alipan）/ 夸克网盘 / 迅雷网盘** 四家，仅在「我的网盘」页面可用。

基于 [YouXiaoHou/panlinker](https://github.com/syhyz1990/baiduyun)（AGPL-3.0）精简重写：去掉远程配置、激活码、广告，修复大文件占内存问题，并持续跟进四家网盘的页面改版。

---

## 特性

- **无服务器依赖**：直链由浏览器直接向网盘官方接口请求，脚本不连任何第三方服务器
- **无远程配置 / 激活码 / 广告**：所有接口硬编码在脚本里，行为不被远端控制
- **大文件友好**：直链交给 aria2 系下载器，断点续传 + 多连接 + 队列，不占用浏览器内存
- **两种导出方式**：RPC 一键推送，或复制 aria2c 命令（已自动附带 UA / Cookie / Referer 请求头，`--out` 自动命名）
- **改版自适应**：勾选识别与按钮挂载均为多级定位 + 兜底策略，网盘小改版不失效
- **可诊断**：Tampermonkey 菜单「📋 复制诊断信息」一键导出排障信息

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)
2. Tampermonkey 面板 → 新建脚本，把 `panlink-lite.user.js` 全文粘贴保存（或将文件拖入浏览器安装）
3. 打开网盘页面，出现「⬇ 直链下载」按钮即成功（悬停按钮可见当前版本号）

## 使用

1. 在网盘「我的网盘」页面勾选文件（可多选）
2. 点「⬇ 直链下载」按钮（统一挂在内容区左上操作按钮排：百度「打开电脑端」旁 / 夸克「添加备份」旁 / 迅雷「传输列表」旁 / 阿里搜索框右侧；找不到时退回右下角悬浮）
3. 弹窗中每个文件 2 个操作：

| 按钮 | 作用 | 配合工具 |
| --- | --- | --- |
| **复制命令** | 复制 aria2c 命令（已带 UA/Cookie/Referer 头，`--out` 自动命名） | 终端 aria2、XDown |
| **RPC** | 推送单任务到 RPC 下载器（推荐） | Motrix、Rayburst、aria2 RPC |

设置入口在弹窗右上角的 ⚙️ 齿轮（Tampermonkey 菜单里也有同名入口）。
小文件直接用网盘网页自带的下载按钮即可，不需要本脚本。

## 下载工具怎么选

| | Motrix / Rayburst | aria2 命令行 / XDown |
| --- | --- | --- |
| 对应按钮 | 推送 RPC | 复制命令 |
| 费用 | 免费 | 免费 |
| 适合 | **大文件挂机、批量队列（推荐）** | 终端党 / Linux / 服务器 |

**推荐**：装 Motrix 或其继任者 Rayburst（原 Motrix Next，4.0 起更名）一个就够（下载大文件的主力）。
「复制命令」可贴进终端（需 aria2）或 XDown 导入。

**Rayburst 用户注意**：RPC 默认端口是 `29100`（不是旧 Motrix 的 16800），且默认启用 RPC 密钥——在脚本「⚙️ 设置」里端口填 29100，密钥去 Rayburst 设置的 RPC 项里复制粘贴。

> NDM / IDM 无法自定义请求头，带不了百度要求的 UA + BDUSS，**不适用**本脚本，见排障。

## 百度网盘配置（仅百度需要，一次即可）

百度取直链走 OAuth，需在 [百度开放平台](https://console.bce.baidu.com/) 有应用：

1. 创建应用（或用已有应用），**安全设置 → 授权回调页** 填 `oob`
2. 把应用的 **AppKey** 填进脚本头部的 `BAIDU_CLIENT_ID` 常量（已预填自用应用）
3. 首次使用会弹一次授权页，同意后 token 自动保存
4. 应用的 **SecretKey / SignKey 是服务端密钥，不要放进脚本、不要外传**（隐式授权用不到它们）

百度直链满速需要超级会员；非会员官方限速。夸克非会员也有限速；阿里免费用户有每日流量配额。

## 已知限制 / 故障排查

- **仅支持「我的网盘」页面**。分享页请先把文件保存到自己网盘再下载
- **按钮点了提示"请先勾选"** → 网盘改版导致选择器失效。先确认文件处于勾选状态，再用 Tampermonkey 菜单「📋 复制诊断信息」导出排障信息
- **百度提示获取 token 失败** → 检查开放平台回调页是否为 `oob`，或重新登录网盘后再试
- **百度下载报 403 / NDM、IDM 无法下载** → 百度直链强制校验 `User-Agent: pan.baidu.com` + BDUSS Cookie，NDM/IDM 不能自定义请求头，直连必 403。百度请走「推送 RPC」或「复制命令」（均已自动带头）
- **阿里下载报 403** → 确认运行的是最新版（v1.7.6 起 Referer 为 `www.alipan.com`），且直链取到后尽快开始下载（有效期短）
- **迅雷下载的文件名/后缀不对** → 迅雷直链 URL 不含文件名，但「复制命令」/「RPC」已用 `--out` 自动命名，用这两种方式下载即正常
- **夸克报 code=undefined** → 夸克接口校验客户端 UA，脚本已伪装为 quark-cloud-drive 客户端；若仍报错，请导出诊断信息反馈
- **夸克/迅雷/阿里直链失效快** → 直链有有效期，取到后尽快开始下载
- **RPC 提示"连不上 RPC 服务"** → 下载器没开或没装（Motrix / Rayburst / aria2 需保持运行）
- **RPC 提示 Unauthorized / 下载器拒绝任务** → 端口或密钥不对。Rayburst 默认端口 29100、默认启用密钥；老 Motrix/aria2 默认 16800、通常无密钥
- **反馈问题** → 先悬停「⬇ 直链下载」按钮确认运行的是最新版本（tooltip 有版本号），再用「📋 复制诊断信息」导出内容连同报错截图反馈
